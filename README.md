# SOLID Principles in C#

Proyecto educativo realizado en C# para explicar e implementar los cinco principios SOLID mediante ejemplos prácticos y comentados.

## Principios incluidos

- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)

## Estructura del proyecto

```text
.
├── Program.cs
└── principioSolid.cs
```

## Objetivo

El objetivo del proyecto es mostrar:

- Problemas de diseño comunes.
- Ejemplos que NO cumplen SOLID.
- Refactorización aplicando buenas prácticas.
- Uso de abstracciones, interfaces y polimorfismo.
- Código comentado paso a paso para estudio.

## Tecnologías utilizadas

- C#
- .NET

## Ejecución

```bash

```

```bash
cd <NOMBRE_DEL_PROYECTO>
```

## Contenido educativo

Cada principio incluye:

- Definición teórica.
- Problema de diseño.
- Ejemplo incorrecto.
- Solución aplicando SOLID.
- Ejemplo funcional ejecutable desde `Program.cs`.
